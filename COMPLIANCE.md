# API Compliance Declaration

This framework is a zero-dependency pure-Python implementation built over `pydantic` and `ml-switcheroo-ir`.
All mathematical and layer computations evaluate in pure Python with zero runtime `numpy` dependency.

- **100% Documentation Coverage**: Maintained.
- **100% Test Coverage**: Maintained (100% line, branch, and function coverage).
- **Strong Typing**: Maintained (`mypy --strict`, zero `Any`/`object`/`cast`/reflection hacks).
- **No Forbidden 3rd Party Dependencies**: Maintained (depends strictly on Python stdlib, `pydantic`, and `ml-switcheroo-ir`).
